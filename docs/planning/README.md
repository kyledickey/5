build-out. These documents are kept for provenance and decision context. They
are **not** maintained alongside the code; the reference docs in
[`../README.md`](../README.md) describe what the backend actually does today.

- [`v5.md`](v5.md): the product definition the backend was built against. Templates own policy, moderators apply templates, cases snapshot the selected result.

- [`v5-product-interview.md`](v5-product-interview.md): the 76 answered product questions that refined `v5.md`.
- [`v5-product-review.md`](v5-product-review.md): implementation review findings that fed the interview.
- [`v5-walkthrough-revisions.md`](v5-walkthrough-revisions.md): behaviour changes made after the walkthrough.
